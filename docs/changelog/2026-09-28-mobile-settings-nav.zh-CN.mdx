# 修复移动端设置导航

在移动端网页中，数据统计、设备、数据存储、凭证管理、API Key、连接器、导入等工作区设置页面缺少对应的路由。点击这些设置入口会落入兜底路由并被重定向回首页，每个受影响的入口都表现得像 "返回首页" 链接。现在所有工作区设置页面在移动端都能正常打开。

## 体验优化与修复

- **所有设置入口都能打开对应页面。** 数据统计、设备、数据存储、凭证管理、API Key、连接器、导入（含 Linear 导入）在移动端网页上正常渲染，不再跳回首页。
- **旧版深链正确落位。** 旧的 `stats`、`creds`、`linear` 地址在移动端会转发到对应的现行工作区设置页面，与桌面端行为一致。
