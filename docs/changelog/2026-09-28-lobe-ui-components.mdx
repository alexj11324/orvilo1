# Interface Components Move to lobe UI

Common interface components across the app — result pages, loading
spinners, file uploads, badges, progress indicators, pagination, popovers,
tooltips, and empty states — now render with Orvilo's own lobe UI component
set instead of the underlying Ant Design versions they previously shipped
with.

This is a consistency change, not a feature change: the same components show
up in the same places and behave the same way. You may notice subtle visual
polish differences — spacing, stroke widths, and progress rendering — as the
surfaces now follow a single design system.

## Improvements and fixes

- Upload drop zones and file pickers now use lobe UI's trigger-style upload
  component; file entry points look and behave consistently across settings,
  import, and attachment surfaces.
- Progress indicators render through lobe UI's unified component, including
  segmented progress such as the memory progress icon.
