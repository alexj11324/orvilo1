# Issue 菜单恢复正常的键盘快捷键

Issue 的状态和优先级菜单仍然支持数字键快捷选择 —— 打开菜单后按 `1`…`9` 即可选中对应行 —— 但不再干扰周围的按键。

## 修复

- **带修饰键的数字不再改动 Issue。** 菜单打开时按 `⌘+1`、`Ctrl+1` 或 `Alt+1`，按键会正常交给应用或浏览器快捷键，而不会再悄悄修改任务的状态或优先级。
- **菜单搜索框里输入数字恢复为过滤文本。** 在菜单顶部搜索框中输入的数字会作为文本保留，可以正常搜索带数字的状态名；只有输入框之外的按键才作为快捷选择生效。
- **输入法组合键与长按重复也安全。** 通过输入法候选上屏的数字、按住不放产生的重复按键，都不会再触发选择。
- **优先级修改失败后加载态正常结束。** 写入失败（或写入途中关闭任务）时，标签会恢复正常状态而不是一直转圈，同一个选择可以再次尝试。
