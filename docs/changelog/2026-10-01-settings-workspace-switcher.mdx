# Workspace Switcher in Settings Sidebar

Workspace settings pages now greet you with the workspace you are managing, not the Orvilo logo. The top of the settings sidebar shows the current workspace's icon and name next to a sidebar collapse control, so it is always clear which workspace's settings you are editing.

Clicking the workspace row opens the full list of your memberships: each workspace shows its icon, name, and member count when available, with a check mark on the active one. Pick another workspace to jump straight into it. The list ends with a **New Workspace** entry that takes you to the workspace creation flow.

## Improvements and fixes

- **The settings breadcrumb is shorter.** The row under the switcher is now just "← Back to app" — the workspace name moved up into the switcher where it belongs.
- **The rest of the app is untouched.** The home sidebar and collapsed icon rail keep the Orvilo logo header exactly as before; the switcher appears only on the workspace settings surface.
