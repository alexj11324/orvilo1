# Execution feedback and connection guide

A missing-device refusal explains the configuration problem in the current language and links to device setup. Technical details start folded. The workspace overview describes activity and provides an execution-setup action before the first run.

The conversation sidebar opens workspace Tasks when the new-chat route has no Agent ID; saved Agent routes keep their Agent-specific Tasks destination. Board descriptions use the existing plain-text summary helper.

The device connection modal fetches CLI release metadata only while open. A verified asset enables the install command; an absent asset shows the release link, and lookup failure offers retry. Long commands scroll horizontally and have named copy controls that copy the full command.

The main and auth shells load the Ant Design reset in the base CSS layer, allowing shared button utilities to retain foreground and typography. Share and Workbench retain their separate CSS ownership. Existing loading treatments remain in place.

Verify actionable refusals, task navigation, long command display/copy and light/dark button colors in the real Electron candidate. The shared browser fixture checks computed foreground tokens across English/Chinese/long labels and 360/1024px widths; its geometry assertions do not certify glyph-ink optical alignment or whole-page accessibility.
