# 任务状态选择与看板保持一致

看板现在是所有任务状态选择器的唯一来源。无论是在移动端还是桌面端打开任务详情、右键点击卡片，还是使用状态子菜单，看到的选项都与看板逐列对应：待分流、待办、待处理、进行中、待审阅、已完成、已取消 —— 顺序与图标都与看板一致。

## 问题修复

- **任务详情页的状态选择器不再停留在旧的四项列表。** 现在它展示看板已知的全部列，包括待分流列和每个状态正确的图标 —— 看板上能看到的状态，现在都能选到。
- **不可达的列会显示但置灰，而不是静默消失。** 暂时无法进入某个仅工作流列的任务（例如尚未关联工作流时的待分流列）仍能看到完整的看板列表，不可达选项处于禁用状态 —— 与在看板上拖拽所允许的范围一致。
- **移动已关联工作流的任务会写入工作流状态。** 为已关联任务选择列时，现在会更新其工作流分类，与在看板上拖拽产生的写入一致，而不是写错状态轴。
