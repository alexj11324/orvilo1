# Getting Orvilo

Orvilo runs wherever you work — browser, desktop, or phone. Sign in once and your Agents, Pages, and Memory stay in sync across every device.

## Platform Overview

| Platform          | Availability    | Get it                                                                        |
| ----------------- | --------------- | ----------------------------------------------------------------------------- |
| **Web**           | Modern browser  | [Open Orvilo](https://orvilo.aspectlylabs.com)                                |
| **macOS**         | Desktop release | [DMG / ZIP](https://github.com/alexj11324/orvilo1/releases/latest)            |
| **Windows**       | Desktop release | [Installer](https://github.com/alexj11324/orvilo1/releases/latest)            |
| **Linux**         | Desktop release | [AppImage / deb / rpm](https://github.com/alexj11324/orvilo1/releases/latest) |
| **iOS / Android** | Mobile web      | [Open in your browser](https://orvilo.aspectlylabs.com)                       |

## Web

No installation required. Open [orvilo.aspectlylabs.com](https://orvilo.aspectlylabs.com) in any modern browser and start immediately. Data syncs to the cloud — switch devices anytime.

**Best for:** Quick access, trying Orvilo before installing, or using it on shared / restricted machines.

## Desktop

Download the installer for your platform from the [latest stable GitHub Release](https://github.com/alexj11324/orvilo1/releases/latest). Choose the ARM64 or Intel build on macOS, the setup EXE on Windows, or a Linux package. The public `/download` entry redirects to the same release.

**Best for:** Connecting local tools and working in a dedicated application window. Agent execution still requires a configured Agent and an available execution device.

## Mobile

Open [Orvilo](https://orvilo.aspectlylabs.com) in Safari or Chrome and sign in with your account. You can add the web app to your home screen using your browser's menu.

Native iOS, Android and APK downloads are not currently published in the Orvilo release channel. Use the mobile web app rather than an unavailable store or APK link.
