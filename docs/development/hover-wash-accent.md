# Hover wash uses the accent role, not muted

`--muted` is the secondary surface (near black in the dark theme), while `--accent` maps to `colorFillTertiary`, the hover wash DESIGN.md defines. Interactive states (hover, focus-visible, expanded, popup-open, active) that painted `bg-muted` went darker than the surface in dark mode and did not match controls using the antd fill tokens beside them. The ghost and outline Button variants and the remaining interactive `bg-muted` states now use `bg-accent`; static `bg-muted` surfaces are unchanged.

Native Electron exposed a retained antd anchor reset outside CSS layers that overrode these utility-layer hover backgrounds on links. Ghost and outline link buttons now give the existing accent hover utility priority only when rendered as an anchor. This does not move global CSS layers or change ordinary button priority. The actual API Docs link was transparent before the fix and used the dark theme's `rgba(255,255,255,0.06)` accent after a full renderer reload. This is a CSS cascade fix; no stylesheet-source string test was added.
