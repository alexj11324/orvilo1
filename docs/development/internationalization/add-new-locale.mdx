# New Locale Guide

Orvilo uses @lobehub/i18n-cli as the i18n solution, which allows for quick addition of new language support in the application.

## Adding New Language Support

To add new language internationalization support in Orvilo (for example, adding Thai `th-TH`), please follow the steps below:

### Step 1: Update the Internationalization Configuration File

1. Open the `.i18nrc.js` file. You can find this file in the project's root directory.
2. Add the new language code to the configuration file. For example, to add Thai, you need to add `'th-TH'` to the configuration file.

```js
module.exports = {
  // ... Other configurations

  outputLocales: [
    'zh-TW',
    'ru-RU',
    'ja-JP',
    // ...Other languages

    'th-TH', // Add 'th-TH' to the array
  ],
};
```

### Step 2: Automatically Translate Language Files

Orvilo uses the `@lobehub/i18n-cli` tool to automatically translate language files, so manual updating of i18n files is not required.

Run the following command to automatically translate and generate the Thai language files:

```bash
bun run i18n
```

This will utilize the `@lobehub/i18n-cli` tool to process the language files.

### Step 3: Submit and Review Your Changes

Once you have completed the above steps, you need to submit your changes and create a Pull Request.

Ensure that you follow Orvilo's contribution guidelines and provide a necessary description to explain your changes. For example, refer to a similar previous Pull Request .

### Additional Information

- After submitting your Pull Request, please patiently wait for the project maintainers to review it.
- If you encounter any issues, you can reach out to the Orvilo community for assistance.
- For more accurate results, ensure that your Pull Request is based on the latest main branch and stays in sync with the main branch.

By following the above steps, you can successfully add new language support to Orvilo and ensure that the application provides a localized experience for more users.
