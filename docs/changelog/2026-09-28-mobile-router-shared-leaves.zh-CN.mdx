# 移动端路由与桌面端保持同步

移动端此前重复声明了一份共享路由表，导致桌面端新增的工作区设置页从未同步到移动端网页，点击后被弹回首页。现在移动端直接消费同一份共享叶子路由注册表 —— 移动端提供的每个页面只声明一次 —— 并有覆盖率测试保证：移动端不提供的路由必须显式列入排除清单。

## 体验优化与修复

- **新页面自动同步到移动端。** 在共享定义中注册一次的工作页面和设置页即可在移动端网页上正常访问，不再需要维护容易漂移的第二份路由表。
- **回归由测试兜底。** 移动端无法提供的共享路由必须显式列入排除清单，缺失的移动端路由会让测试失败，而不是悄悄把用户弹回首页。
