# Inter Variable

Unmodified font assets from `@fontsource-variable/inter` **5.3.0**:
<https://registry.npmjs.org/@fontsource-variable/inter/-/inter-5.3.0.tgz>

Copyright and SIL Open Font License 1.1 are preserved in `LICENSE.txt`.
Upstream metadata is preserved in `metadata.json`. Standard normal and italic
styles include weight and optical-size variation and all upstream subsets.
CSS uses subset unicode ranges so the browser only fetches needed files.

Imported by Project Layout and bundled by the existing Web/Electron pipeline.
No font was copied from the authenticated reference application.

Project Layout references `LICENSE.txt` through a static `new URL(..., import.meta.url)`
asset dependency and renders a `rel="license"` link. This keeps the complete
copyright/OFL notice in the deployed renderer assets, not just the source tree.
