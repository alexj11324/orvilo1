# 界面组件统一迁移至 lobe UI

应用内的常用界面组件 —— 结果页、加载动画、文件上传、徽标、进度条、分页、
气泡卡片、文字提示与空状态 —— 现已统一使用 Orvilo 自己的 lobe UI 组件
渲染，不再使用底层的 Ant Design 版本。

这是一次一致性调整，而非功能变更：同样的组件出现在同样的位置、保持同样
的行为。你可能会注意到一些细微的视觉差异 —— 间距、描边宽度与进度条渲染
方式 —— 因为各界面现在遵循同一套设计体系。

## 体验优化与修复

- 上传拖拽区域与文件选择入口统一为 lobe UI 的触发式上传组件，设置、导入
  与附件等入口的外观和行为保持一致。
- 进度指示统一使用 lobe UI 组件渲染，包括记忆页的分段式进度图标。
