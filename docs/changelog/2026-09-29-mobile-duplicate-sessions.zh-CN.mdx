# 修复移动端会话列表重复出现自定义助理

移动端首页的会话列表会累积多个一模一样的「自定义助理」。背后的操作
型请求（「新建助理」按钮使用的请求钩子）继承了 SWR 的默认行为：
请求失败后按指数退避无限重试（首次约 5 秒，随后不断拉长）。创建
会话并不是幂等操作，每一次重试都会再插入一对「助理 + 会话」记录
—— 移动网络下丢一次响应，一次点击就会变成一连串重复创建。

现在操作类请求失败后不再自动重试，错误只会上报一次，需要用户再次
主动点击才会重新发起。新增的回归测试保证失败的操作请求不会被重复
调用。

## 改进与修复

- 「新建助理」失败后不再在后台重复插入会话，重试必须由用户再次
  主动点击。
- 同样的修复覆盖了共享该请求钩子的其他操作，例如新建话题。
