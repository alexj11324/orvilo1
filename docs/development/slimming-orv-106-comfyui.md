# ORV-106 — Remove ComfyUI/artwork/image-generation stack

Linear: ORV-106 ("Remove ComfyUI/artwork/image-generation stack unless retained").

Deletes the entire BYOK media-generation surface: ComfyUI + image + video generation
backends, their client storefronts, and the model-runtime `createImage`/`createVideo`
extension points. Scope also covers the sibling video-generation surface and the
model-bank `type: 'image'`/`type: 'video'` card catalog.

## Deleted

### Client

- `src/features/ArtworkStudio/`, `src/features/ProfileArtwork/`, artwork store slice,
  `Conversation/store/slices/generation`, artwork routes (`/artwork` pages).
- Builtin tool `orvilo-image-generation` package (`packages/builtin-tool-image-generation`)
  plus registration/catalog/engineering references (`builtinToolManifests`,
  `serverRuntimes/imageGeneration.ts`, tool inspector/render wiring, builtin-agent
  example refs repointed to `orvilo-agent-documents`).

### Server

- Lambda routers: `comfyui`, `image/`, `video/`, `generation`, `generationBatch`,
  `generationTopic` + their tests; registrations removed from `routers/lambda/index.ts`.
- Async routers: `async/image.ts`, `async/video.ts`, `async/contentPolicyError.ts`,
  `async/imageError.ts` + tests.
- Services: `services/comfyui/` (entire package incl. config/registry/workflowBuilder/
  tests+fixtures), `services/generation/`, `services/aiGeneration/`.
- WebAPI `webapi/create-image`, webhook `webhooks/video/:provider` handler + registration.
- `taskResultBridge` image/video legs.

### Model runtime / model bank

- `packages/model-runtime`: `types/image.ts`, `types/video.ts`, `createImage`,
  `createVideo`, `handlePollVideoStatus`, `handleCreateVideoWebhook`,
  `AuthenticatedImageRuntime`, `ModelRuntime.getAuthHeaders`, `PromptTransform`
  utilities, `isAutoGeneratedImageModelId`, `imageGeneration` cost resolver.
- Media-only providers removed entirely: `bfl`, `fal`, `replicate`, `comfyui`
  (runtime adapters, provider cards, env plumbing).
- `packages/model-bank`: `const/imageParameters.ts`, `const/standard-parameters.ts`,
  `ModelParamsSchema`, all `type: 'image'`/`type: 'video'` model cards across every
  provider file (google/vertexai/aihubmix/openrouter/zenmux/...), `providerCard.parameters`,
  `enabledImageAiProviders`/`enabledVideoAiProviders` in `AiProviderRuntimeState` and the
  aiInfra repo filters.
- `packages/utils/src/number.ts` (dead once standard-parameters went away).
- `packages/types`: `ComfyUIKeyVault`, `ClientSecretPayload.authType`, generation asset
  types consumed only by the deleted stack (schema file inlines the asset shape until
  ORV-108 drops the tables).

### CLI / desktop / misc

- `apps/cli`: `generate image|video|status|download|list` commands; generate.md skill
  reference rewritten to text/tts/asr only.
- Dockerfile ComfyUI env plumbing, `package.json` media-provider deps, env docs.
- SWR image keys, generation-topic system-agent selector, related tests/snapshots.

### Locales

- `builtins.orvilo-image-generation.*`, `promptTransform.*`, `systemAgent.generationTopic.*`,
  `plans.features.imageGeneration/videoGeneration`, `unlock.comfyui.*`,
  `unlock.apiKey.imageGenerationDescription` across `packages/locales/src/default`,
  `locales/en-US`, `locales/zh-CN`.

### Docs

- `docs/development/basic/comfyui-development.*`, `add-new-image-model.*`,
  `self-hosting/faq/vercel-ai-image-timeout.*`, `usage/providers/comfyui.*`;
  provider list + model-provider env docs trimmed; `product-scope.md` superseded note.

## Kept (deliberate)

- `services/aiGeneration` core retained only where referenced by still-live flows
  (see issue comments); `ChiefAgent/artwork.ts` stays pending ORV-107 conversation work.
- **Native image-output chat models** (`type: 'chat'` cards with `abilities.imageOutput`,
  e.g. `gemini-*-image-preview`): kept, including `Pricing.approximatePricePerImage`,
  `ExtendParamsType` members `imageAspectRatio`/`imageAspectRatio2`/`imageResolution`/
  `imageResolution2`, and the chatConfig → modelExtendParams → ChatStreamPayload →
  provider `chat()` mapping (google `imageConfig`, openrouter `image_size`).
- Chat-model abilities `imageInput`/`imageOutput`/`video` and pricing units
  `imageInput`/`imageOutput`/`videoInput`/`'second'` (used by live chat cards).
- `AgentRuntimeError` ComfyUI\* members + `errors/specs.ts` + `Conversation/Error` rendering
  — persisted historical tool/agent errors still deserialize through these codes.
- `toolRenderRules` `isImageBearingTool` literals — renders for persisted historical
  tool messages.
- `SpendType` image/video billing categories + notification icon map — historical
  billing records still carry them.
- Drizzle schema `schemas/generation.ts` (tables `generations`, `generationBatches`,
  `generationTopics` + `idGenerator` prefixes `gb`/`gt`) — table drops deferred to ORV-108;
  `GenerationAsset` shape inlined locally so the schema compiles without `@orvilo/types`
  generation module.
- `AiModelTypeSchema` `'text2music'`/`'realtime'` literals (catalog enum surface).

## Route reservation

`RESERVED_RETIRED_ROOTS` already covers `/image` and `/video` (redirect to `..`), so no
router changes were needed beyond removing the page segments.
