# Issue Status picker matches the board

The Status menu on an issue page now lists the same states as the kanban board, in the same order and with the same icons and names. Triage appears first, as it does on the board, so an issue's Status and the column it sits in can never disagree again.

## Improvements and fixes

- **Triage is selectable.** The Status menu offered only a partial list and dropped the triage state entirely; it now shows all seven workflow states the board has.
- **One source for icons and labels.** The menu previously drew its own labels, so "Pending review" on the board read "In review" on an issue. Options and the row itself now read the board's own column names, and picking an option writes exactly what a drag into that column would.
