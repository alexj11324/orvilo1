## 4. 待运行时验证项

1. **Built-ins 产品决策**（DIRECTORY-BUILTINS-ASSESSMENT 三选一）是最大阻塞：未决定前，参考端空态无法对齐，D9 的死代码问题也无法闭环。
2. **Shared 组**：需要一个他人 `visibility=workspace/team` 的视图进 `Shared with me` 组，验分组、行点击、无删除菜单。
3. **Owner 列 / 署名的取舍**：若决定对齐参考端列模型，需要先确认 `SavedViewItem` 是否能拿到 owner 显示名（`rich-rows-facets.next-slice.md` 已记 `SavedViewItem` 不含 owner 名）。
4. **多组并存时表头重复 + 列宽漂移**（D8）：mine + built-in 同时出现时目测一次。
5. 详情页菜单补齐与否的产品决策（D13：Subscribe/Copy link/CSV export 等）。
6. Facet tabs（D14）依赖 server facet 契约扩展（assignee、labels）—— 属数据模型工作，不在 UI 切片内。
7. 参考端「有数据目录」的 Display options 行为只观测到菜单内容物，排序 / 属性切换未在参考端点过 —— 候选端若要实现需先补参考端运行时观测。
8. 候选端目录暗色 / 390px 窄屏 / 键盘操作（行 `Enter`/`Space` 已接 `onKeyDown`）未验。
