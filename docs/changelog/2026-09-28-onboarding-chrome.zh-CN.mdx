# 更简洁的 Onboarding 顶栏与加载态

Onboarding 向导的顶栏不再显示应用的语言切换和主题切换按钮 —— 这些控件
属于登录后的应用外壳，不属于初始化流程。步数计数保留，你仍然可以
看到当前进度。

在 Onboarding 开始阶段加载个人资料时，页面现在会一直显示头部和品牌
标识加加载指示器，而不是在空白页面上只显示一个加载图标。

## 改进与修复

- 移除了 Onboarding 顶栏的语言和主题控件，保留步数计数。
- Onboarding 加载态现在在加载图标外渲染页面头部，弱网下页面不再
  显示为空白。
