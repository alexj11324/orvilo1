# 更清晰的工作区标识冲突提示

当创建工作区的标识（slug）已被占用时，接口现在会返回明确的冲突错误，API 调用方和重试逻辑可以据此区分「换一个标识」与真正的服务器故障。同样的修正也覆盖了委派任务创建路径：输入重复时不再误报为内部错误。

## 体验优化与修复

- **重复的工作区标识返回冲突错误。** 工作区创建接口现在能识别被包装的数据库错误，返回冲突而非通用服务器错误。
- **委派任务输入在重复时正确报错。** Agent 委派路径以同样方式识别被包装的唯一键冲突错误。
