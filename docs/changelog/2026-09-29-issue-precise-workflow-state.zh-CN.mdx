# Issue 状态菜单支持选择精确团队工作流状态

现在所有 Issue 状态选择器都共享团队的真实工作流状态。当一个类别映射到多个团队状态时 —— 例如同一列下的「进行中」与「已暂停」—— 每个状态都会作为独立的菜单项出现在详情页属性栏、列表行、看板卡片和右键菜单中，选中即写入该精确状态。

## 改进

- **所有入口都能选精确状态。** 详情页、列表行、看板卡片菜单和右键菜单都按看板类别顺序列出团队工作流状态，使用看板图标，并在当前状态上打勾。
- **统一写入命令。** 所有选择器都通过同一条带领域版本检查的看板移动命令提交 —— 任意入口的选择都会携带精确状态引用、刷新后保留，并在数据已被改动时给出明确的冲突提示。
- **歧义类别移动仍会询问。** 拖动或选择映射到多个团队状态的纯类别时，仍会打开既有的状态选择器；取消则不写入任何内容。
- **运行状态保持独立。** Agent 执行状态 (运行中、失败、需要输入) 保持在独立维度 —— 工作流选择不会覆盖它们。
