# Issue 附件遵守编辑锁

当其他人持有编辑锁时，Issue 的说明是只读的 —— 但附件按钮此前并不理会这一点。现在回形针与它要写进的正文共享同一套编辑能力。

## 修复

- **说明不可编辑时，附件按钮禁用。** 在锁状态解析中、其他人正在编辑、或你只有查看权限时，按钮会展示原因提示，而不是打开一个注定写入只读编辑器的文件选择器。
- **过迟的文件选择会被丢弃而不是写入。** 文件对话框需要操作时间；如果你打开选择器后切换到了另一个 Issue，或在选中文件前失去了编辑锁，之前的选择仍会被插入 —— 写进错误的 Issue 或已锁定的 Issue。现在会在对话框关闭时，按发起时的 Issue 与当前编辑权限重新校验，无法写入时会给出提示。
