# 移动端 “会话” 页恢复渲染，不再重复生成助理

移动端网页上围绕助理列表的两处修复：

## 改进与修复

- **工作区内的 “会话” 页恢复渲染。** `/{workspace}` 索引路由此前声明了不带元素的 index 子路由，导致 “会话” 标签经 `/agent` -> `/{slug}` 重定向后落在空的 outlet 上，整页空白。现在它与根路径 `/` 一样挂载主页布局与会话列表。
- **刷新不再重复生成助理。** 工作区缓存作用域重载会广播重验证所有已挂载的 SWR hook，包括 fetcher 为变更操作的 action hook —— 空会话分组上的 “+” 按钮会因此重放 `createSession`，每次作用域切换或刷新都新增一条 “自定义助理”。现在 action hook 统一注册在带前缀的 key 下，广播会跳过它们，而按钮自身的触发不受影响。
