# Orvilo execution and evidence contract

This adaptation retains the upstream phase structure and inspection checklist.
Upstream source: <https://github.com/JCodesMore/ai-website-cloner-template> at
`0fc4dca34fcfcfd32108fb67118aa897a6045414`; MIT license is retained.
The upstream directory is provenance only, not an alternate active skill.

## Existing application, real outcomes

- Use the existing React/TypeScript, base-ui, antd-style, SPA router, SWR,
  Zustand, TRPC and database conventions. Read the applicable repository skills.
- Preserve Orvilo branding and agent-domain surfaces explicitly outside parity.
  Do not copy private user content, avatars, proprietary fonts or brand assets
  into distributed files without the necessary authorization.
- Inspect reference assets and layout layers even when they cannot be reused.
  Record the constraint and permitted equivalent instead of silently omitting it.
- Reuse real domain models. Do not rename knowledge bases as documents, return
  simulated saves, or weaken permissions to imitate a reference screenshot.
- Preserve current worktree changes and live services. Use scoped checks and
  gitmoji checkpoints on the current task branch. Full CI follows the user's
  scheduling constraint, not an upstream per-section build loop.

## Evidence before conclusions

- Record URL, revision/build if known, time, viewport, theme, locale, role and
  relevant data cardinality for each state. Compare matching states.
- Empty, one-item and many-item states are distinct. A control absent in an
  empty state is not proven absent in a populated state. Failed searches,
  inaccessible routes and virtualized offscreen content are not absence proofs.
- Before removing a control, establish comparable-state evidence. When evidence
  is missing or contradicted by the user, withdraw the conclusion, preserve the
  existing behavior and investigate. Never delete fixture records to fake parity.
- Separate observed facts, inferences and unknowns in every specification.
  Unknown is not N/A. A spec cannot certify its own correctness.
- Measure the actual rendered text spans and pseudo-elements as well as their
  containers. Record truncation/omitted nodes in bounded DOM extraction; inspect
  omitted subtrees before claiming complete coverage.
- Collector writes topology, component inventory, per-state behavior and CSS
  specifications before the corresponding implementation. Primary agent checks
  consequential interpretations and the evidence, then approves dispatch.
  Collection may be delegated; acceptance may not be self-approved by its author.

## Browser safety and state ownership

- Use CDP and DOM against authenticated Linear and actual Electron. No CUA,
  Accessibility or Screen Recording requests. Verify target and hit location.
- Coordinate one navigation owner per shared target. Inspection scopes do not
  authorize creating another user's records, sending invitations or deleting data.
- Inventory all controls, but only exercise known read-only reference actions.
  A config field claiming read-only is not proof that an action is safe.
- For writes, use an explicitly authorized disposable/local fixture and verify
  final server state, refresh persistence, permissions and failure recovery.
- If the required reference state is absent, seek an existing authorized example
  or ask for a suitable test fixture. Do not infer its UI from the empty state.

## Assembly and acceptance

- Check whole-page structure, missing/excess controls, ordering and conditional
  presence before fine pixel adjustments. Repeat after component assembly.
- Visual checks cover equal viewports plus narrow/short windows, focus/hover,
  loading/error and modal background composition. Separate font/environment
  differences from product defects; never mask an entire disputed control.
- Behavior checks compare transitions and resulting state, not just clicked
  labels or route success. Persistence and permission outcomes are separate gates.
- Run existing scoped regression tests; tests passing do not establish parity.
  A single observed-match transition is not a whole-page certificate.
- Record source revision with evidence and synchronize gaps to Linear.
  Keep sensitive captures local when publication is not authorized; report the
  unmet publication requirement instead of retrying blocked uploads.
- Completion requires coverage of the original page/state inventory, independent
  acceptance and all applicable final gates. Partial packets remain partial.
