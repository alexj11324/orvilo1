# 创建工作区自动填充工作区 URL

创建工作区这一步现在会跟随你输入的工作区名称自动填入工作区 URL，规则和你手写的一致：小写、连字符分隔、可直接提交。你仍然可以把它改成自定义 URL；清空你的修改后会恢复自动建议。

## 体验优化与修复

- **工作区 URL 跟随名称生成。** 输入工作区名称即给出可直接使用的 URL 建议，第二个输入框不再需要你从零填写。
- **尊重手动输入的 URL。** 一旦你手动改过 URL，它就不再跟随名称变化；清空后恢复自动建议。
