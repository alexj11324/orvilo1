---
title: 凭证迁移至 Orvilo 自有存储
description: 凭证记录改由 Orvilo 自有数据库保存，不再依赖外部 Market 服务，负载全程加密并保留原有的工作区共享模型。
---

## 新功能

- **自有凭证存储**：`credentials` 现在保存在 Orvilo 自有数据库中。每条凭证使用独立的加密 payload 字段（键值环境变量 / 请求头、文件引用、OAuth 连接指针），采用与 API Key、连接器相同的 `KeyVaultsGateKeeper` 静态加密。
- **本地化的共享模型**：个人凭证可以作为私密草稿或正式发布共享到工作区，工作区级凭证与原先的组织维度行为一致 —— 工作区页签会合并组织凭证与成员共享的凭证，并保留所有者归属信息。
- **运行时注入保持不变**：`creds.inject` 仍在沙箱会话内写入 `~/.creds/env`，并在响应中对取值做脱敏处理，Agent 运行链路无需感知明文。
- **仍留在 Market 的部分**：Agent 市场浏览、OAuth 连接代理（令牌托管与连接健康状态）以及技能凭证声明。因此 OAuth 凭证取值仅保留元数据，不参与注入。

## 优化

- **API 形态不变**：新增的 `creds` 与 `workspaceCreds` 路由沿用现有过程名与出入参结构，客户端迁移成本最小；凭证 id 变为 `cred_` 前缀字符串。
