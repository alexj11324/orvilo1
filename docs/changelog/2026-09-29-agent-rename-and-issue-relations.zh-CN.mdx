# 统一 “智能体” 命名，任务侧栏更简洁

过去产品里同一个概念混用了 “assistant”“agent”“助理” 三种说法。现在所有面向用户的标签、按钮、提示、空状态与 CLI 文案统一为 “Agent / 智能体”，包括分享导出的对话与集成说明。

任务详情页的 “关联” 栏不再提供手动关联入口：编号输入框与 “添加关联” 按钮已移除 —— 事项关系应来自提及、引用、同步与智能体工具，而不是人工维护。该栏目更名为 “前置任务”，只列出真正会阻塞运行的阻塞依赖，仍可从列表中移除失效的阻塞项。

## 改进与修复

- **统一术语。** 应用、新手引导、设置与 CLI 中所有面向用户的 “assistant / 助理” 文案均改为 “Agent / 智能体”。
- **更简洁的事项侧栏。** 移除详情栏中的手动 “关联事项” 入口；保留的 “前置任务” 栏只展示阻塞依赖，空态、阻塞中与就绪提示不变。
