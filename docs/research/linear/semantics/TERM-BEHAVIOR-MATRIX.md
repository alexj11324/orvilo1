> **作者**：semantics（第 9 个横切 owner）。审计对象是**含义与行为**，不是像素。
> **方法**：每条 Linear 语义先查官方文档（`linear.app/docs`，独立搜索，不引用 sibling 转述），
> 再用只读 CDP 在登录参考端 `linear.app/bdiverifier`（CDP `:9222`，公约见 `CDP-ETIQUETTE.md`）
> 抽样实测；Orvilo 侧以源码为准（types/schema/model/router/feature/locale 逐行引用），
> 候选端未起本地实例的行在证据列标注「source-only」。

## 判定图例

| verdict       | 含义                                                                                           |
| ------------- | ---------------------------------------------------------------------------------------------- |
| ✅ aligned    | 名称与行为语义一致（含合理的无行为差异重命名）                                                 |
| 🔀 rename     | **different name, same meaning**—— 概念等价但标签不同；记录映射，是否回改由 surface owner 决定 |
| ⚠️ diverge    | **same name, different meaning/behavior**—— 同名（或同位）但语义 / 行为不同，必须修行为        |
| ⛔ missing    | Linear 概念在 Orvilo 完全缺失（含被诚实禁用 / 省略的）                                         |

| ❓ unverified | 证据不足，结论存疑                                                                             |
