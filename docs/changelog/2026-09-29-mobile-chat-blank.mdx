# Fix a blank white screen on the mobile chat page

On the mobile web, the workspace home route (`/:workspaceSlug`) had an index
route declared with no page attached. Anything that landed there — the Chat
tab's route resolution and the chat page's back affordance among them —
rendered an empty white screen under the bottom tab bar.

The index now bounces to the personal home (the session list), matching how
the desktop workspace index bounces to its home surface. A router-level
regression test keeps the slot from silently going blank again.

## Improvements and fixes

- The Chat tab and chat back affordance now land on the session list instead
  of a blank white screen.
- Deep links to `/:workspaceSlug` on mobile web redirect to home rather than
  rendering nothing.
