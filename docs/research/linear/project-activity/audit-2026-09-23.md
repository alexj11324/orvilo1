**feed 条目类型（候选端实际）**：

1. task 字段变更行 ×6 类 —— `status` / `priority` / `assignee_agent` / `assignee_user` / `reviewer` / `automation`，服务端 `task_activities` keyset 分页（50 / 页），actor/target 已解析成 name+avatar（`project.ts:95-180`）。
2. update/comment 行 —— `projectUpdates` 表 `kind: update|comment` 全量（不分页），与 activity 行按 `createdAt` desc 归并（`ProjectActivityPage.tsx:336-348`）。
3. 项目创建行 —— 客户端合成，钉在流末尾（`ProjectCreationActivity`）。
4. **缺**：里程碑事件、项目属性变更事件、评论卡片的独立视觉与交互（reaction/reply/options）。

**update composer（ORV-125 现状）**：

- 输入：Lexical 富文本（link/list 插件），`min-height 32 / max-height 240`，autoFocus，aria-label 随 mode 切换；⌘/Ctrl+Enter 提交；`defaultExpanded`/`emptyState`/`onExpand` 三种挂载形态（Activity 常驻展开、Overview 折叠入口跳 Activity）。

## 6. Project Issues 细节盘点

- **分组**：`groupBy` ∈ none/status/assignee/member/priority + `subGroupBy` 同集（去重）；组头 sticky accordion + 计数 + 折叠（本地态）；组序按 rank+label。
- **排序**：`orderBy` ∈ status/priority/updatedAt/createdAt/assignee/title + direction + completedByRecency；分页集合（mine/scheduled）钉住 ordering/showSubTasks。
- **筛选**：项目作用域内**仅** `?projectMilestoneId=`；visibility chip 项目作用域隐藏；无通用 Add filter。
- **list/board**：全局 `taskListViewMode`；项目默认 list；board = `KanbanBoard` 状态列（支持 assignee/member/priority 列分组）；里程碑过滤强制 list。
- **里程碑过滤**：见 §4 过滤行。
- **父子缩进**：`nestedSubTasks` 默认开 → `buildTaskRows` 组内树化、depth×20px + 肘线、跨组父行 muted 上下文、`showSubTasks=false` 时按成员资格折叠子行。
- **空 / 错 / 载**：骨架 5 行；`AsyncBoundary` block error + Retry；`Empty` 通用空态；hidden-completed footer（带 Show）与截断 footer。
