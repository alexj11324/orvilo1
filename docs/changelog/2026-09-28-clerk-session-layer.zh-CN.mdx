# 登录迁移至账户门户

登录现已完全由 accounts.aspectlylabs.com 账户门户接管。应用内的登录、
注册、验证邮箱与重置密码页面不再渲染本地表单，而是跳转至门户；退出登录
也会同时结束门户会话。

在门户登录后，应用会把门户的 Clerk 会话兑换为 Orvilo 会话 Cookie，因此
回到应用时无需再次登录即可直接进入。已有会话在过期前继续有效，过期后只需
在门户重新登录一次即可。

密码与单点登录（SSO）管理也移至门户 —— 设置页中对应的密码与已关联账户
条目改为说明这一变化，不再提供本地操作。桌面端与命令行的授权流程保持不变。

## 体验优化与修复

- 退出登录现在会跳转至门户并结束 Clerk 会话，而不仅仅是清除应用的本地
  会话 Cookie。
