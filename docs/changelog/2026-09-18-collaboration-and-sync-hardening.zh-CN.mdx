# 协作与同步加固

## 体验优化

- **权限回收精确断开对应的连接。** 移除项目成员现在只会断开该项目房间及其任务房间的连接，而工作区级移除仍会断开该租户的所有房间 —— 过期或重放的回收也不会再误踢事后被重新授权的连接。
- **公开项目的成员不再被误踢。** 对于仍然可以通过公开可见性访问的项目，移除显式席位不会再断开你的实时连接 —— 终止式踢出只保留给真正关闭房间访问的回收动作。
- **网关升级可以安全滚动。** 协作网关会在内部发布响应中标注协议版本，因此旧版本网关在排空期间对项目 / 任务级回收会返回可重试而非静默丢失。

## 问题修复

- **Linear 导入不再被长阶段拖垮。** 工作区级导入现在会在运行中续约租约，规模较大的团队或 issue 扫描不会再让仍在工作的导入器因锁过期而丢失进度提交。
- **新手引导不会再错认领他人的工作区。** 创建工作区现在在检查点记录的 id 下进行：重试或丢失的创建响应按身份匹配恢复，而不是按可能已被他人占用的 slug 匹配。
- **Responses API 如实汇报委派运行。** 等待子助理调用的运行会一直保持在 `incomplete` 直到子任务完成，而不是提前汇报截断的 `completed`。
