# 团队资源、可拖拽收藏与诚实的显示选项

团队主页的 Documents 标签不再是占位空态。成员可以创建团队页面、附加链接、用分节组织内容，刷新后列表保持一致 —— 数据严格限定在团队范围内，读写均有工作区隔离与权限校验。创建者退出后，团队页面与其历史仍然保留。

侧边栏收藏的排序方式与预期一致：指针拖动行，或使用键盘与菜单中的 “上移 / 下移”—— 三种方式共用同一套排序契约。拖拽松手不会触发跳转，新顺序在重新加载后保留；遇到并发冲突时刷新并给出反馈，而不是静默失败。

项目的显示选项面板改为真实的能力矩阵。每个可以开启的选项都会实际改变列表 —— 布局、分组、排序和逐属性列 —— 并作为个人偏好持久化。暂时无法生效的选项保持禁用并在提示中说明原因，不再出现看似可点却毫无作用的控制。

## 体验优化与修复

- **删除团队页面后，团队主页的资源行立即消失**，无需手动刷新。
- **项目详情与列表控件与 Linear 参考对齐**，仅支持表头排序的属性也保持一致。
- **导航时侧边栏保持展开**，桌面导航面板不再因拖拽误折叠。
- **工作区文档搜索遵循团队页面权限**：成员可见，团队外用户不可见。
