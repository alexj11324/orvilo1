# 移动端会话页变成真正的对话列表

移动端会话页现在像聊天应用一样工作，而不是智能体目录页。

## 改进与修复

- **对话优先，智能体退居元数据。** 会话页按最近活跃排序列出工作区内的对话：
  每行以对话标题为主视觉，所属智能体仅以状态标记 + 名称弱化为次级信息。
  「deepseek-v4-flash」这类原始模型角标从导航中移除 —— 模型属于配置，只在设置中出现。
- **「+」开启新对话。** 顶部按钮在最近使用的智能体上开新会话（无对话时回落到
  Orvilo AI），不再新建智能体卡片。
- **搜索搜索对话。** 会话页搜索栏现在跨智能体过滤对话，而不是列出匹配的智能体卡片。
- **智能体管理收进设置。** 「我 → 设置 → 智能体」打开智能体管理页，档案 / 模型 / 工具等
  配置都在那里完成。底部标签栏保持四个入口不变。
- **标签栏不再遮挡内容。** 标签栏适配 iOS 底部安全区，收件箱 / 我的事项等页面
  为固定栏预留空间，列表末尾可以滑到。
