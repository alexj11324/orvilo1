# 从详情页把 Issue 归档到项目

此前 Issue 右侧栏中的「项目」行只是一个链接 —— 点击跳到项目页，没有项目时整行干脆不显示。现在它是一个编辑器，与下方的里程碑选择器一致。

## 修复

- **项目行成为选择器。** 可编辑的 Issue 会看到一个列出所有可见项目的下拉菜单 —— 与侧栏相同的按权限过滤的列表 —— 当前归属已勾选，底部提供「无项目」项。换项目、给无项目的 Issue 归档、清除归属都会通过常规的 Issue 更新保存，并刷新详情、Issue 列表以及两个项目的任务目录。
- **导航保留为独立动作。** Issue 已归属项目时，行尾的小箭头负责打开项目页 —— 从菜单选择不会跳转页面，点击箭头也不会改变归属。
- **不兼容的里程碑按原有服务端规则处理。** 移到其他项目的任务，只有在新项目确实存在对应里程碑时才会保留里程碑行，与服务端的项目变更语义一致。
