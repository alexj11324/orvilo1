## Existing Orvilo adapter is not wired to inference

`packages/agent-execution/src/controlPlane/primeRuntime.ts` launches `--mode acp`, sends initialize, then `session/new` with an empty MCP list. Its options have no inference broker, custom provider registration, extension injection, or broker IPC attachment. A comment about trusted brokers does not install one. The current adapter therefore cannot establish that any Prime inference passes through `createInferenceBroker`.

## Implementable integration boundary

The supported custom API `registerProvider(...streamSimple...)` is the broad interception point because ordinary streaming and completeSimple use the API registry. A trusted launch integration must register a dedicated broker-only API/model route before session creation and ensure all selected models, compaction/refinement models and child sessions use it. The custom handler must translate the Prime event-stream protocol and communicate over a supervisor-provided local IPC channel to an Orvilo host broker. Never put a real provider URL, provider credential, vault reference, or provider error body in that handler's arguments, process environment, model configuration, or kernel files. If an upstream model configuration needs a baseUrl/key placeholder, it must be an explicitly inert non-secret local identifier, with network blocked and no fallback provider path; this has not been implemented or validated here.

IPC needs host-bound session/tree identity; the host must derive tenant/principal/task/grant/fence and authorized binding from that attachment, not trust child-supplied authority fields. Allow only approved model-route IDs and bounded inference payloads. The host resolves secrets/endpoints, checks live grants/lease/revisions before outbound admission and while streaming, and returns whitelisted semantic events. Abort/closed IPC must cancel provider iteration and pending billing/network admission. Process-tree termination remains supervisor-owned. Do not make a local socket pathname or child-provided fence the sole authorization mechanism.

An Agent.streamFn override can be useful for a narrowly scoped SDK test but does not cover the direct completeSimple paths above. ACP filesystem/terminal permission denial also does not implement inference transport. A production integration must deny provider network access from the entire tree and prevent provider-registry fallbacks or extension-defined alternate transports; registration alone is not isolation.

## Contract gap and acceptance required

The restored broker supports text messages and text/usage/error output. Prime's actual protocol includes toolCall/toolResult messages and toolcall event sequences (`packages/ai/src/types.ts:182,229–230,262–272`). Silently flattening or dropping those values cannot provide a functioning tool-capable Prime agent. The shared contract needs a reviewed capability-aware representation, or unsupported content must fail closed. No new contract is invented in this source audit while the original contracts patch is missing.

Acceptance must cover ordinary prompts, inline and runtime-host children, compaction, branch summaries, refinement, cancellation, revocation/rotation during streaming, denied alternate routes, denied direct network, and inaccessible auth files/environment. Only then can the adapter claim production broker coverage. After the original contracts patch was restored, the Linux guard suite passed 10/10 on 2026-09-30 at 16:37:50 UTC. Running the same suite against the preserved original broker produced 8 failures and 2 passes; the fixed broker passed 10/10 again. Logs are under `/workspace/scratch/core-validation/inference-{original,fixed}-regressions.log`. These tests use explicit authority/backend fixtures and execute the real guard; they are not provider execution or production IPC evidence. Static hook discovery is not backend execution evidence.
