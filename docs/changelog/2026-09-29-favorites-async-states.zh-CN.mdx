# 侧栏收藏现在展示真实的加载与错误状态

之前收藏分组在 “请求还在加载”“请求失败”“真的没有收藏” 三种情况下显示
完全一样 —— 都是一个空面板。现在每种状态都有独立呈现：首次加载时显示行级
骨架屏；首次请求失败时显示紧凑的 “加载失败” 行并附带重试入口；只有请求真正
返回空列表时才显示 “暂无收藏” 提示。

如果已加载的收藏在后台刷新时失败，现有行会保留在原位，并追加一条不阻塞的
“刷新失败” 提示和重试按钮，而不是伪装成收藏被清空。

## 改进与修复

- 首次加载中显示两行骨架，而不是空白面板。
- 首次加载失败显示行内错误与可用的重试入口，不再与空态混淆。
- 确认返回的空列表显示轻量的 “暂无收藏” 提示。
- 重验证失败保留当前行并附加重试提示，不会清空你的收藏。
