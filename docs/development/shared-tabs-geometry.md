# Shared segmented tabs

Segmented tabs use a 28px outer control, 24px triggers and a 2px inset. The active surface fills the trigger; labels and icons share that height. The line variant retains its underline geometry. Inbox and Reviews use the shared control instead of overriding the selected background or padding. Changing tabs preserves their existing URL and unread-count behavior. This styling change does not change page loading geometry.
