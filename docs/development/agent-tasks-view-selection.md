# 任务列表视图选择

`AgentTasksPage`（`src/features/AgentTasks/AgentTaskList/`）在 board 与 list 两种视图间切换。本文记录视图选择的不变量——由 `AgentTasksPage.test.ts` 中的用例钉死。

## 不变量

- 视图选择由用户显式偏好决定，**不随任务数量变化**。任务从 0 条变 1 条（或反向）时，board/list 不得自动跳变。
- 空态（0 条）有自己的渲染分支；从空态进入非空态时保留用户已选的视图。

## 背景

修复前视图在任务数量跨越 0↔1 边界时会跟随数量跳动：board 视图在收到第一条任务时被切到 list。根因是视图选择被绑在集合规模上而不是用户选择上。修复后视图只读用户偏好，数量变化只影响列表内容。
