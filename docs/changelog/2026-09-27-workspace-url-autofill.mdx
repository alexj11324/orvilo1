# Workspace URL Auto-Fill in Onboarding

The workspace step of onboarding now fills in the workspace URL automatically as you type the workspace name, matching what you would write yourself: lowercase, hyphenated, and safe to submit. You can still replace the suggestion with a custom URL, and clearing your edit restores the suggestion.

## Improvements and fixes

- **Workspace URL derives from the name.** Typing a workspace name proposes a URL-safe slug so the second field is no longer a blank chore.
- **Manual URLs are respected.** Once you edit the URL field it stops following the name; clearing it resumes the automatic suggestion.
