# Workspace Switcher in the Sidebar Header

The top of the main sidebar is now your workspace, not the Orvilo logo. A single row shows the current workspace's icon and name with the notifications and sidebar-collapse controls on the right, so it is always clear which workspace you are working in.

Clicking the workspace row opens the full list of your memberships: each workspace shows its icon, name, and member count when available, with a check mark on the active one. Pick another workspace to jump straight into it. The list ends with a **New Workspace** entry that takes you to the workspace creation flow.

## Improvements and fixes

- **Settings sidebars are cleaner.** Workspace and personal settings no longer carry the app header row — their rail starts directly with a single clickable "← Back to app" item, styled like every other navigation row.
- **The rest of the app is untouched.** Nav groups, the collapsed icon rail, and the workspace avatar menu in the footer all behave as before.
