# 议题状态选择器与看板保持一致

议题页的状态菜单现在与看板列出完全相同的状态，顺序、图标和名称一致。「待分流」排在最前，与看板一致，议题的状态与它所在的列从此不会再不一致。

## 体验优化与修复

- **可以选择「待分流」。** 状态菜单此前只提供了一部分状态，完全缺失「待分流」；现在展示看板上的全部七种工作流状态。
- **图标与名称统一来源。** 菜单此前使用自己的一套名称，看板上的「待审阅」在议题页显示为「审核中」。选项与状态行现在都读取看板列自身的名称，选择某个选项写入的就是把卡片拖入该列时会写入的状态。
