## Boundary enforcement is CI-forced, not documentation-only

`Slimming Boundary` runs `node scripts/slimming/census.mjs --check` inside `Required Quality Gate`
on every code-affecting change (ORV-110). A PR that makes live code import a retired path — or
recreates files under a DELETE glob and links them in — fails the required check with the offending
importers listed. The ledger (`boundary.json`) is the machine-readable source of truth; this audit
is a point-in-time rendering of it.
