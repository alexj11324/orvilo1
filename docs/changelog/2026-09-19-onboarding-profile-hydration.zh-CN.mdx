# Onboarding 保留已保存的设置

在冷刷新后打开 Onboarding 向导时，表单可能在已保存的资料到达前就捕获了浏览器探测到的默认值，此时直接提交会把已保存的时区覆盖为探测值。现在向导会先等待设置加载完成（或加载失败）后再展示第一步。

## 体验优化与修复

- **冷刷新不再丢失已保存的资料字段。** 向导在已保存的姓名、时区和遥测偏好可用前显示短暂加载态，而不是先用探测默认值初始化表单。
- **设置加载失败不再卡住向导。** 用户状态获取失败时，Onboarding 仍会以默认值打开，而不是一直停在加载中。
