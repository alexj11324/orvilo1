# 修复移动端会话页白屏

在移动端网页中，工作区首页路由（`/:workspaceSlug`）的索引路由声明时
没有绑定页面。任何落到这里的导航 —— 包括「会话」标签的路由解析和
会话页的返回按钮 —— 都会在底部标签栏上方渲染出一片空白。

现在该索引会跳转到个人首页（会话列表），与桌面端工作区索引跳转到
主页面的行为一致。新增的回归测试保证这个位置不会再静默变白。

## 改进与修复

- 「会话」标签和会话页返回按钮现在落到会话列表，不再是白屏。
- 移动端深链到 `/:workspaceSlug` 会重定向到首页，不再渲染空白。
