# 获取 Orvilo

Orvilo 随你所在 —— 浏览器、桌面或手机均可使用。登录同一账号，助理、文稿和记忆在所有设备间保持同步。

## 平台一览

| 平台                | 可用形式  | 获取方式                                                                          |
| ----------------- | ----- | ----------------------------------------------------------------------------- |
| **网页**            | 现代浏览器 | [打开 Orvilo](https://orvilo.aspectlylabs.com)                                  |
| **macOS**         | 桌面发行包 | [DMG / ZIP](https://github.com/alexj11324/orvilo1/releases/latest)            |
| **Windows**       | 桌面发行包 | [安装程序](https://github.com/alexj11324/orvilo1/releases/latest)                 |
| **Linux**         | 桌面发行包 | [AppImage / deb / rpm](https://github.com/alexj11324/orvilo1/releases/latest) |
| **iOS / Android** | 移动网页  | [在浏览器打开](https://orvilo.aspectlylabs.com)                                     |

## 网页端

无需安装。在任意现代浏览器中打开 [orvilo.aspectlylabs.com](https://orvilo.aspectlylabs.com)，即可开始使用。数据同步至云端，随时切换设备。

**适合：** 快速访问、安装前试用，或在共享 / 受限设备上使用。

## 桌面端

从[最新稳定版 GitHub Release](https://github.com/alexj11324/orvilo1/releases/latest)下载对应平台的安装包。macOS 请选择 ARM64 或 Intel 架构，Windows 选择 setup EXE，Linux 选择对应软件包。公开 `/download` 入口也会跳转到同一个发行版。

**适合：** 连接本地工具、在独立应用窗口工作。执行任务仍需要已配置的 Agent 和可用的执行设备。

## 移动端

在 Safari 或 Chrome 中打开 [Orvilo](https://orvilo.aspectlylabs.com)，使用同一个账号登录。也可以通过浏览器菜单将网页应用添加到主屏幕。

Orvilo 发行通道目前没有发布原生 iOS、Android 或 APK 下载。请使用移动网页，避免跳转到不可用的商店或 APK 链接。
